# Agent Skills and operating rules

Use the local SPECTION skills in `.agents/skills`: product-brief, requirements, hld, lld, adr, feature-spec, quality-gate, security-review and release.
Workflow: review brief and PRD, map requirements, implement bounded changes, run actual tests, record evidence, request human review. Never use real student data, secrets or fabricated test results. Do not expand scope without approval. See docs and specs before editing code.
